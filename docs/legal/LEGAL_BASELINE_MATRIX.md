## Единая матрица реализации
Норма -> категория ВС/процедура -> участник -> данные/документ -> источник -> полномочие -> срок -> подпись -> решение -> хранение -> тест. Допуск обязательного правила только после сверки действующей редакции и точного пункта. Повторное использование актуальных подтвержденных сведений; обязательные новые подтверждения отдельно. Интерфейс: отклонения, сроки, действия; полная информация в меню.
