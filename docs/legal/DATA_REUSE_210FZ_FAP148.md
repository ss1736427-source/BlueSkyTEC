# Повторное использование данных: 210-ФЗ и ФАП-148
Сверка 27.11.2026: https://www.consultant.ru/document/cons_doc_LAW_103023/a593eaab768d34bf2d7419322eac79481e73cf03/ ; https://www.consultant.ru/document/cons_doc_LAW_506938/38c2238797bbb90bd8dc8771a5016bf0410cfcc8/ ; https://base.garant.ru/412107352/53f89421bbdaf741eb2d1ecc4ddb4c33/ .
210-ФЗ ст.7 ч.1 пп.1–3: запрет лишних требований; получение сведений из распоряжения соответствующих органов с исключениями ч.6; межведомственные действия не перекладывать на заявителя с установленными исключениями. Не распространять автоматически на частную аккредитованную организацию. Полный перечень ч.6 и ст.7.1–7.2 требуют отдельной сверки.
ФАП-148 п.25: 12 календарных месяцев; п.26 новое заявление; п.27 шесть категорий приложений: заключение не ранее 30 календарных дней до подачи, отчет ТО, отчеты директив, отчет изменений конструкции, перечень отложенных дефектов, копия разрешения радио при наличии. П.29 допускает запрос документов п.48. П.47–48 документарная проверка и осмотр сохраняются; комплект представляется аккредитованной организации. Повторное использование не означает освобождение от представления комплекта.
Проектная зависимость: идентификатор ВС -> версия первичной записи -> доказательство и подтверждение -> проверка актуальности и применимости -> формирование комплекта -> обязательная подпись/проверка -> решение -> архив. Не переносить подписи на новое заявление. Для каждого поля фиксировать источник, дату, подтверждающее лицо, срок, применимость, обязательность нового подтверждения и допустимый канал. Не считать прием подтверждением. Не запрашивать повторную загрузку если допустимо автоматическое включение; межведомственный запрос только при законном доступе. Не считать отсутствие ответа подтверждением.
Тесты: неизменившиеся сведения наследуются; изменившиеся актуализируются; истекшие и противоречивые не считаются действительными; заключение старше 30 дней не допускается; осмотр не пропускается; комплект воспроизводим; исключения ч.6 учитываются после сверки. Экран только отклонения и критические сроки, полный обзор через меню.
Статус: проверены указанные нормы по справочным источникам; официальная сверка, полный перечень исключений, регламент услуги, межведомственные полномочия и юридическая допустимость каналов остаются открытыми. Программный механизм не реализован.
