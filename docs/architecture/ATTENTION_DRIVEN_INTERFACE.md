# Обязательный контракт интерфейсов BlueSky TEC
Требование владельца проекта: интерфейсы соответствуют формам и требованиям законодательства РФ, максимально разгружены; выводится только то, что требует внимания.
## Разделение
Рабочий экран — активные задачи, отклонения, необходимые решения и подписи. Официальная форма — полный состав нормативных реквизитов, установленная структура, применимая редакция, подписи и формат. Не сокращать обязательную форму ради удобства. Полные документы, статусы и история доступны по запросу в пределах полномочий.
## Поведение
Успешные автоматические проверки и завершенные действия не выводить в активные задачи, но сохранять результаты. Показывать приближение срока, недостаточность данных, несоответствие, необходимое действие, подпись, решение, сбой автоматизации. Не скрывать обязательные уведомления. Не считать отсутствие данных успешной проверкой. Не смешивать предупреждение и юридическое решение. Пороги раннего предупреждения — проектные настройки, отдельно от нормативных сроков.
## Карточка внимания
ВС/дело, причина, нормативное основание (если применимо), срок, необходимое действие, ответственный, ссылка на документ и доказательства. Объединять повторные сигналы об одной причине, не теряя исходные события. При устранении закрывать задачу с сохранением истории. Пользователь видит задачи своей роли и существенные для него изменения; не раскрывать чужие закрытые данные.
## Формы
Для каждой формы вести нормативный источник, редакцию, обязательные поля, условную применимость, источник автозаполнения, подписанта, канал передачи. Не требовать повторного ввода подтвержденных сведений. Перед подписанием доступна полная форма для проверки. Подписанные версии неизменяемы; исправления через предусмотренную процедуру. Не подменять установленный бумажный оригинал цифровым без правового основания.
## Приемочные критерии
При отсутствии отклонений список задач пуст; доступ к полному досье сохраняется. При появлении проблемы отображается конкретное действие, а не весь чеклист. После устранения запись исчезает из активных задач, но воспроизводится в истории. Официальная форма содержит все обязательные реквизиты независимо от состава рабочего экрана. Проверка полномочий и нормативная трассируемость обязательны. Программная реализация и проверка конкретных форм предстоят.
